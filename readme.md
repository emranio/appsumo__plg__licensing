# Appsumo v2 licensing plugin for WordPress

## Installation
To install the plugin, run the following command:
```bash
composer install
```

## Configuration
All configuration settings can be found in the config.php file.

## Signup page
Complete signup page's HTML in the templates/signup.php file. CSS and JS are already enqueued and can be found in assets directory.

## Changing the Prefix
To change the prefix _plg_ in this plugin, perform a global find and replace with your desired word. Replace _plg_ with _word_ case sensitively.
